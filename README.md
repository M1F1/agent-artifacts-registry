# AART Reference Registry

Public, version-independent [`M1F1/agent-artifacts-registry`](https://github.com/M1F1/agent-artifacts-registry) registry compiled by
[AART](https://github.com/M1F1/agent-artifacts) from the reviewed source commit
[`716051ecb968af109c11dd6c8c28cd6a467d986a`](https://github.com/M1F1/agent-artifacts/commit/716051ecb968af109c11dd6c8c28cd6a467d986a).

Install or subscribe to this registry with AART. Treat its manifests, provenance, lock, and
compiled index as the source of truth; do not edit generated lock/index files by hand.

Every artifact declares its own license. Security evidence describes installation risk and never
constitutes a guarantee that an artifact is safe.
